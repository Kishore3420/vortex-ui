# Button Components Tutorials

## Overview

Interactive button components with premium animations and effects.

## Tutorials

- [Shimmer Button](shimmer-button-tutorial.md) - Glossy shimmer effect
- [Border Beam Button](border-beam-button-tutorial.md) - Animated border beam
- [Ripple Button](ripple-button-tutorial.md) - Material ripple effect
- [Magnetic Button](magnetic-button-tutorial.md) - Magnetic cursor attraction
- [Glow Button](glow-button-tutorial.md) - Glowing hover effect
- [Interactive 3D Button](interactive-3d-button-tutorial.md) - 3D tilt effect

## Quick Start

```tsx
import { ShimmerButton, MagneticButton } from '@/components/ui';

<ShimmerButton>Premium CTA</ShimmerButton>
<MagneticButton>Magnetic Effect</MagneticButton>
```

## Use Cases

- **CTAs**: Shimmer, Glow
- **Navigation**: Magnetic, Ripple
- **Premium Actions**: Border Beam, 3D
